📚 SmartStudy

SmartStudy là hệ thống quản lý học tập dành cho sinh viên, giúp quản lý tập trung các hoạt động học tập như môn học, bài tập, lịch học, điểm số và tài liệu.

Tính năng
+ 🔐 Đăng ký, đăng nhập và xác thực JWT
+ 📊 Dashboard tổng quan việc học
+ 📚 Quản lý môn học
+ 📝 Quản lý bài tập và deadline
+ 🗓️ Quản lý lịch học
+ 📈 Quản lý điểm
+ 📄 Quản lý tài liệu học tập
+ 🤖 Chat hỗ trợ học tập bằng AI
